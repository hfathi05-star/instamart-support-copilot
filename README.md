# Instamart Support Copilot

## Project Overview
AI-powered customer intelligence and support copilot developed as an AI/ML capstone project.

## Project Components

### Part A – Data Foundation
- Synthetic data generation
- Data cleaning and preprocessing
- SQLite database creation
- Customer data preparation

### Part B – Customer Analytics
- Customer exploratory data analysis
- Customer segmentation
- Customer lapse prediction

### Part C – Support Ticket Triage
- Ticket classification
- PII redaction
- Retry handling and validation
- Priority and routing analysis

### Part D – Policy RAG & Refund Agent
- Policy document retrieval
- TF-IDF similarity matching
- Policy retrieval evaluation
- Refund support agent
- Evaluation using 14 policy questions

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- SQLite
- TF-IDF
- Git & GitHub

## Project Structure
- `data/` – datasets and policy documents
- `notebooks/` – exploratory analysis
- `src/` – Python source code
- `tests/` – project tests
- `outputs/` – generated results

## Installation

```bash
pip install -r requirements.txt
```

## Execution
Run the Python scripts from the project root directory.
